# Microservices Monitoring Platform

Java microservices platform for monitoring and maintenance, built with Spring Cloud.

## Architecture

- API Gateway for routing requests
- Eureka Server for service discovery
- Config Server for centralized configuration
- Surveillance Service for monitoring workflows
- Maintenance Service for maintenance workflows
- Notification Service for notifications

## Technologies

- Java
- Spring Boot
- Spring Cloud
- Eureka
- API Gateway
- Centralized configuration

## Project Structure

```text
projet-microservice/
├── api-gateway/
├── config-server/
├── eureka-server/
├── maintenance-service/
├── notification-service/
└── surveillance-service/
```

## Purpose

This project demonstrates how a monitoring and maintenance solution can be organized with independently deployable microservices.
